# Sales Performance Analysis Dashboard

## Objective
Analyze business sales data to identify revenue trends, top-performing products, and business growth opportunities.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboard Design

## Dataset
Superstore Sales Dataset

## Key Insights
- Technology category generated highest revenue
- West region performed best
- Sales increased during seasonal periods
- Few products generated major revenue

## Recommendations
- Increase promotions for high-performing products
- Improve campaigns in weaker regions
- Focus inventory planning during peak seasons
